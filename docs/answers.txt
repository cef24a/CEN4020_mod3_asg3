5. What is the difference between git log and git status? (4 points)
	
	"git log" shows what commits have already been made previously as well as 
	their corresponding information, but "git status" shows what is about to be 
	commited (what is staged to be committed soon, if a file has been modified 
	but not added/ staged yet, etc.)

8. In the context of object-oriented programming (I) What is inheritance? (II) 
What is polymorphism? (III) What is encapsulation? (6 points)
	
	I. Inheritance is when one class *inherits* the attributes of another class. 
	In this repo's code, it could be said that the Bike and Car classes
	*inherit* the Vehicle class's attributes because bikes and cars are kinds of
	vehicles. This is evident in how the car and bike classes have the
	properties of a vehicle like 'brand' and 'model'.
	
	II. Polymorphism sort of expands on inheritance in that if one object
	inherits from another object, they may be able to override a parent method
	with their own unique version. An example of this in the code is how the Car
	object can override the regular Vehicle object's toString() method. While a 
	Vehicle would just respond with the string describing the Vehicle's brand
	and model, if the code sees that the Vehicle is--in fact--a car, then it can
	give the special response of the PoweredVehicle's toString() method 
	(which just gives us the fuel type) and add on the engine size at the end 
	of the string.
	
	III. Encapsulation is when attributes of a class are only accessed via
	getter and setter methods so as to not overwrite / lose important 
	information. For a Car object, this would be like how we can get and set the
	engine size, but not to anything we want. Because it wouldnt make sense to
	have size 'yellow' engine, for example, we only allow the options to be
	'small', 'medium', 'grande', or 'unknown' via this method.
